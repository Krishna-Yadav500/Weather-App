# Weather App with JavaScript

A dynamic and responsive weather application that provides real-time weather data for any city using the OpenWeatherMap API.

## 🚀 Features
* **Real-time Weather Data:** Fetches current temperature, humidity, and wind speed.
* **Dynamic Icons:** Changes weather images (Cloud, Clear, Rain, Mist, Snow) based on current weather conditions.
* **Location Search:** Allows users to search for weather by entering a city name.
* **Error Handling:** Displays a "Location not found" 404 message if the city entered is invalid.
* **Responsive Design:** Clean, centered UI that works across different screen sizes.

## 🛠️ Tech Stack
* **index.html**: Defines the app structure, including the search box and weather display areas.
* **style.css**: Modern dark-themed styling with a clean white container and custom button hover effects.
* **script.js**: Handles API integration, asynchronous data fetching, and DOM manipulation.

## 📦 How to Run
1. Clone this repository.
2. Ensure you have the necessary image assets (`404.png`, `cloud (1).png`, `clear.png`, etc.) in the project folder.
3. Open `index.html` in any modern web browser.
